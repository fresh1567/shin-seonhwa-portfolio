01 / 직무와 적합성

임상 이해를 고객 도입과 운영으로

신선화 | 헬스케어 사업기획 · 고객 도입·운영

제안하는 역할

병원 고객의 요구를 파악하고, 제안·도입·이용 안내·후속 운영을 연결하는 실무형 사업기획 역할입니다.

이미 수행한 경험

외과계 중환자실 간호 경험, 수면관리 서비스 기획·PM, 건강 데이터 연계 서비스 설계, 기업 임직원 건강관리 프로그램 운영, 위험 알림 앱 제품 출시 경험이 있습니다.

확인된 범위

기업 임직원 프로그램 운영 대상 약 3,000명 이상 / 12주 수면관리 프로그램 기획 / 위험 알림 앱 제품 출시 완료·시판 준비. 운영 대상 규모는 활성 이용자 수나 참여율과 다릅니다.

보완할 영역

의료 GPO의 구매·조달·정산 운영은 직접 수행한 경력으로 제시하지 않습니다. 입사 초기에 제품·거래 조건과 병원별 업무 절차를 배우고, 임상 및 B2B 운영 경험을 고객 요구 파악과 안내 설계에 적용하겠습니다.

02 / 큐로직 사업 이해

구매·물류·고객·정산이 연결되는 구조

Q-Platform 공식 서비스 소개를 바탕으로 정리한 사업 이해

오픈마켓형 GPO

병원과 공급사에 열린 구매 플랫폼입니다. 참여 주체가 늘면 제품·조건의 선택 폭과 거래 기회가 넓어지는 구조로 이해했습니다. 고객 도입 기획은 병원의 구매 요구와 공급사의 제품·거래 조건을 함께 이해해야 합니다.

물류와 자동주문

공식 소개는 사용부서의 사용량·재고 파악, 처방연동 자동주문, 전용 물류센터와 사용부서 맞춤 배송·적재를 설명합니다. 실제 병원별 적용 범위와 연동 방식은 도입 시 확인할 항목입니다.

고객·정산 관리

구매와 물류에 더해 고객·정산 관리를 통합합니다. 주문부터 납품·사용·정산까지 정보와 담당자가 이어지는 구조가 중요하다고 판단했습니다.

병원 업무 흐름 맵 · 제안용 개념도

  1. 요구 파악
  2. 구매 조건
  3. 발주
  4. 입고·검수
  5. 재고·사용
  6. 정산 확인

사용부서 요구 → 구매 조건 확인 → 발주 → 입고·검수 → 재고·사용 → 정산 확인. 구매팀은 품목·거래 조건, 사용부서는 규격·사용성, 물류 담당은 재고·납품, 약제부는 해당 의약품 업무, 정산 담당은 거래 증빙을 확인하는 구조로 가정합니다. 실제 역할 분담은 병원별로 검증합니다.

03 / 문제와 개선 가설

첫 과제는 고객이 막히는 지점을 찾는 일

아래 세 과제는 현황 확인 후 검증할 개선 가설입니다.

01 직접 소싱·시장조사 부담

가설: 품목 규격과 거래 조건을 같은 형식으로 정리하면 검토와 문의의 반복을 줄일 수 있습니다. 산출물: 병원 요구사항·품목 조건표, 공급사 확인 질문 목록. 측정: 최초 문의부터 제안까지 시간, 조건 누락으로 인한 재문의 건수.

02 원내 입고·출고 관리

가설: 담당자와 처리 기준을 명확히 안내하면 도입 초기 업무 누락을 줄일 수 있습니다. 산출물: 부서별 도입 체크리스트, 입고·검수·출고 안내. 측정: 도입 리드타임, 미완료 항목 수, 운영 문의 건수.

03 의료인력의 발주·재고 부담

가설: 자동주문 적용 조건과 예외 상황을 설명하면 이용 과정의 혼선을 줄일 수 있습니다. 산출물: 주문·예외처리 흐름, 역할별 안내와 FAQ. 측정: 사용부서 이용률, 수동 보정 건수, 주문 오류·문의 건수.

현재 구조 → 검증할 개선 구조

현황 확인 전 가정부서별 확인 → 담당자 확인 → 개별 문의
검증할 개선 흐름체크리스트 → 조건·예외 안내 → 후속 대응 기록

수행 전후 성과가 아닌 제안 비교입니다. 현재 가정: 부서별 반복 확인 → 담당자 확인 → 개별 문의. 제안: 역할별 체크리스트 → 조건·예외 안내 → 담당자 연결 → 현황·후속 대응 기록. 먼저 현장을 확인한 뒤 적용할 항목을 정합니다.

04 / 첫 90일 실행안

학습 → 작은 도입 실험 → 운영 개선

담당 범위와 현황을 합의한 뒤 조정하는 실행 초안

1–30일 | 현황과 기준선

구매·물류·정산 담당자에게 업무를 배우고 병원 고객의 문의·도입 흐름을 파악합니다. 산출물: 이해관계자 맵, 도입 체크리스트 초안, 문의 유형표. 기준선: 단계별 처리시간, 문의 건수, 미완료 항목.

31–60일 | 안내와 도입 실험

합의된 대상 고객·사용부서에 개선 안내를 적용하고 내부·공급사 담당자의 피드백을 확인합니다. 산출물: 역할별 안내, FAQ, 주문 예외처리 흐름. 측정: 안내 이후 재문의, 체크리스트 완료율, 도입 단계별 소요시간.

61–90일 | 운영 점검과 다음 과제

이용 현황과 고객 문의를 묶어 반복 문제를 정리하고 후속 대응 담당자와 개선 우선순위를 합의합니다. 산출물: 운영 현황·후속 대응 목록, 다음 분기 개선안. 측정: 지속 이용·재주문, 문의 재발, 미해결 건수.

지표 운영 원칙

목표 수치는 기준선과 데이터 수집 가능성을 확인한 뒤 합의합니다. 완료율은 완료 항목/전체 항목, 재주문율은 재주문 고객/측정 대상 고객처럼 분모와 관찰 기간을 먼저 정의합니다. 매출·수주 성과나 절감률을 사전에 약속하지 않습니다.
