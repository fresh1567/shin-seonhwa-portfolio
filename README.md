# 신선화 포트폴리오

의료 현장 경험, 디지털 헬스케어 서비스 기획, B2B 고객 운영 역량을 보여주는 한국어 단일 페이지 포트폴리오입니다.

**공개 사이트:** https://fresh1567.github.io/shin-seonhwa-portfolio/

## 구성

- `index.html` — 전체 콘텐츠와 접근 가능한 문서 구조
- `styles.css` — Clinical Intelligence / Calm Precision 디자인과 반응형 레이아웃
- `script.js` — 모바일 메뉴, 업무 방식 탭, 프로젝트 상세 패널, 모션그래픽 및 3D 제어
- `healthcare-mobius.glb` — Blender에서 다시 열 수 있는 경량 Hero 3D 모델
- `portfolio-hero-mobius.png` — WebGL 미지원·데이터 절약 환경용 Hero 대체 이미지
- `assets/projects/` — 원본 포트폴리오·소울 서비스 소개서와 삼성화재 공식 소개에서 발췌한 프로젝트 화면
- `shin-seonhwa-career-profile.pdf` — 생년·전화번호·주소·사진을 제외한 공개용 경력기술서
- `404.html` — GitHub Pages용 오류 안내 페이지

별도의 빌드 과정은 필요하지 않습니다. 실시간 3D는 버전이 고정된 Three.js 0.128.0과 GLTFLoader를 jsDelivr에서 불러오며, 외부 스크립트나 WebGL을 사용할 수 없는 환경에서는 정적 이미지가 자동으로 표시됩니다.

## 모션 및 3D

- GLB 모비우스 모델의 완만한 자동 회전과 포인터 반응
- 의료 데이터 흐름을 표현한 궤도·파티클·노드 모션
- 스크롤 진행 표시, 주요 수치 카운트업, 카드별 인포그래픽 모션
- 화면 밖 또는 백그라운드 탭에서는 3D 렌더링 일시 정지
- 데이터 절약 모드에서는 정적 이미지 우선
- `prefers-reduced-motion`에서는 자동 회전·패럴랙스·반복 모션 중지

## 로컬 확인

프로젝트 폴더에서 정적 서버를 실행한 뒤 브라우저로 접속합니다.

Node.js 등의 정적 파일 서버로 이 폴더를 열어 확인합니다.

그다음 `http://localhost:4173`을 엽니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소 기본 브랜치에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 기본 브랜치와 `/ (root)` 폴더를 지정하고 저장합니다.

사이트는 저장소가 공개인 경우 보통 `https://계정명.github.io/저장소명/`에서 열립니다. 실제 주소는 GitHub Pages 설정 화면에서 확인하세요.
